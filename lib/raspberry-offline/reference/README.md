# Local validation references

Host-specific validation snapshots do not belong in the repository.

Local reference snapshots are stored below:

    a local reference directory outside the repository

That directory is intentionally excluded from Git.

Repository status of this method:

- Backup implementation: verified on a laboratory ARM64 system
- Restore implementation: not yet verified
- Generated initramfs images: never stored in Git
- Real host configurations: never stored in Git
